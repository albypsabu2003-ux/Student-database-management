# Student Database Management System (SLL)

A modular, C-based Student Database Management System developed using the Singly Linked List (SLL) data structure for efficient student record management and dynamic memory allocation.

## Features

The system allows users to add, delete, modify, and sort student records dynamically. It also supports persistent data storage using file handling (`student.dat`) to maintain student information. The project follows a modular C programming architecture with a main source file (`stu_main.c`), separate functional modules, and custom header files.

## Compilation & Execution

The project can be compiled and executed using the included Makefile. Use `make` to compile the program, `./student` to run the executable, and `make clear` to remove the compiled binaries and object files.
